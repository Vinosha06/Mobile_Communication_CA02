## ✨ Key Features Implemented
* **Firebase Authentication:** Secure Email & Password login with error handling and logout functionality.
* **9 Unique Designs:** Each member screen uses distinct layouts, color palettes, typography, and Flutter widgets.
* **State Management:** Implemented using `setState` (for interactive like/favorite counters, loading indicators, and UI state updates).
* **Asset Management:** Member photographs loaded cleanly from `assets/images/`.
